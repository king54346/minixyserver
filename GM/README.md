# 小妖怪 GM 工具

本地网页版 GM 工具，管理云服 121.37.152.248 上的游戏数据。

## 启动

1. 第一次用先装依赖：`pip install paramiko`
2. 双击 `启动GM工具.bat`（或命令行 `python gm.py`），浏览器会自动打开 http://127.0.0.1:8765
3. 在页面右上角输入服务器 root 密码，点「连接」。

密码只保存在这个进程的内存里，不写到任何文件；关掉黑色窗口工具就退出了。

## 功能

- **玩家列表**：显示所有角色的 uid、名字、等级、是否在线，可以按名字或 uid 筛选。
- **角色数值**：选中玩家后可以改元宝、银两、魂值、友情点、等级、经验、VIP、体力、活力。
  - 只提交改动过的项。
  - 玩家在线时会先被踢下线再改。在线时游戏里存着一份角色数据，不踢下线的话改动会被它覆盖。
- **踢下线**：把选中的玩家踢下线。
- **改成完美账号**：满级、全护法满神通、满装备和法术书、元宝和银两。
  - 原有的护法、装备、法术书会被整体替换。
  - 闯关进度等其它数据保留。
- **发放物品**：通过邮件发给选中的玩家或全服，玩家在游戏邮件里领取。
  - 可以发元宝、银两、魂值，以及道具、护法卡、装备、法术书。
  - 物品按名字或编号搜索，点一下加入列表，再改数量。

## 原理

本机的 `gm.py` 只监听 127.0.0.1。页面上的操作会经 SSH 转到云服，在服务器上用 curl 调游戏服的本机管理接口
（127.0.0.1:28418，对外不开放）。管理接口在 `server/internal/xymsrv/admin.go` 和 `gm.go` 里：

| 接口 | 用途 |
|---|---|
| `GET /players` | 玩家列表 |
| `GET /player?uid=` | 角色详情 |
| `GET /catalog` | 可发放的物品目录 |
| `POST /role` | 改角色数值 |
| `POST /kick` | 踢下线 |
| `POST /perfect_uid` | 改完美账号 |
| `POST /mail` | 发邮件 |

## 可选的环境变量

- `XYM_SSH_HOST`：服务器地址，默认 121.37.152.248。
- `GM_PORT`：本地网页端口，默认 8765。
