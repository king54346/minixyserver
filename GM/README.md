## 启动

1. 第一次用先装依赖：`pip install paramiko`
2. 双击 `启动GM工具.bat`（或命令行 `python gm.py`），浏览器会自动打开 http://127.0.0.1:8765
3. 在页面右上角输入服务器 root 密码，点「连接」。

密码只保存在这个进程的内存里，不写到任何文件；关掉黑色窗口工具就退出了。

## 功能

- **玩家列表**：显示所有角色的 uid、名字、等级、是否在线，可以按名字或 uid 筛选。
- **角色数值**：选中玩家后可以改元宝、银两、魂值、友情点、等级、经验、VIP、体力、活力。
  - 只提交改动过的项。
  - 玩家在线时会先被踢下线再改。在线时游戏里存着一份角色数据，不踢下线的话改动会被它覆盖。
- **踢下线**：把选中的玩家踢下线。
- **改成完美账号**：满级、全护法满神通、满装备和法术书、元宝和银两。
  - 原有的护法、装备、法术书会被整体替换。
  - 闯关进度等其它数据保留。
- **发放物品**：通过邮件发给选中的玩家或全服，玩家在游戏邮件里领取。
  - 可以发元宝、银两、魂值，以及道具、护法卡、装备、法术书。
  - 物品按名字或编号搜索，点一下加入列表，再改数量。

## 原理

本机的 `gm.py` 只监听 127.0.0.1。页面上的操作会经 SSH 转到云服，在服务器上用 curl 调游戏服的本机管理接口
（127.0.0.1:28418，对外不开放）。管理接口在 `server/internal/xymsrv/admin.go` 和 `gm.go` 里：

| 接口 | 用途 |
|---|---|
| `GET /players` | 玩家列表 |
| `GET /player?uid=` | 角色详情 |
| `GET /catalog` | 可发放的物品目录 |
| `POST /role` | 改角色数值 |
| `POST /kick` | 踢下线 |
| `POST /perfect_uid` | 改完美账号 |
| `POST /mail` | 发邮件 |

## 可选的环境变量

- `XYM_SSH_HOST`：服务器地址，默认 121.37.152.248。
- `GM_PORT`：本地网页端口，默认 8765。

默认仍走SSH隧道，双击原启动器即可。`启动二服GM工具.bat`保留二服主机、管理端口30988和本地网页端口8766。可用`python gm.py --direct --admin http://127.0.0.1:28418`切到已有本地隧道的直连模式，或用`--tunnel --ssh-host <主机>`指定SSH模式。配置优先级为命令行、环境变量、同目录gm.conf、默认值；配置不保存密码。
- `XYM_ADMIN_PORT`：服务器本地管理端口；一服默认 28418，二服默认 30988。

## 定时福利、概率与审计

一服双击 `启动GM工具.bat`，二服双击 `启动二服GM工具.bat`（二服网页端口 8766）。连接对应服务器后打开顶部“发奖与掉落”或“全服播报”。密码仍只保存在本机进程内存，不写入脚本。

### 灵活发奖

“当天登录”“达到指定活跃度”“发奖时在线”三个条件独立选择；全不选为无条件。满活跃度为 125，数据读取服务端当天真实记录，读取失败或角色正忙会跳过并稍后重试。登录记录从本次功能上线后开始采集，不能将历史在线推算为已登录。

支持每天定时、当天条件达成立即发送、指定日期单次发送；可限定日期范围、UID 名单或新角色天数。不填 UID 表示全服；新角色天数为 0 表示不限制建角日期。

“全服七天·每天50万模板”预填连续七个自然日、每天 500000 元宝，默认暂停。按需要修改起止日期和条件，先预览名单，再设为启用并保存。日期范围是全服统一七天，不按每个账号注册时间重新计七天。

调度器在游戏服务器运行，每 30 秒检查；关闭 GM 网页不影响任务。定时规则到点后持续检查到当日结束，当天晚些达标仍可发送。未达标的日期不补发。规则编号、奖励日期、UID 组成唯一发奖键，与邮件在同一数据库记录提交；重复执行、重启不会重复发同一天同一规则的邮件。已有规则保持原编号，新建另一编号会视作另一项活动。

### 抽卡与开箱

五种卡池分别设置星级权重、五星保底抽数（0 关闭）、十连最低星级（0 关闭）；每日推荐还支持独立稀有概率。设置立即生效，无需重启。保底、十连保证和独立稀有都会影响最终出金率，界面的自然概率不包含保底。

三种宝箱分别设置每项奖励、数量、权重及返还宝箱概率。每箱独立随机，不设强制出金保底。可提高碎片权重、降低或关闭整件权重。`GPSP5` 是随机五星法术碎片，`GPJT5` 是随机五星装备碎片，`GPFS5`/`GPZB5` 是随机五星整件；定时邮件使用具体道具编码，不能填这些随机奖励编码。

“降低出金预设”会填入超级请神符及每日推荐自然五星权重 1%、50 抽保底、十连至少四星；每日推荐独立稀有概率 0.3%。黄金宝箱降低五星整件、提高五星碎片权重。点击“保存抽卡及全部宝箱设置”后生效；“原始预设”也需要保存才生效。其他卡池可分别编辑。配置带版本校验，多窗口同时修改时旧窗口需要重新读取，避免覆盖新配置。

### 查谁在什么日期领了什么

页面下方按日期、UID 和事件类型读取服务器日志。“发放邮件”记录奖励归属日、UID/角色名、规则编号、邮件编号及具体奖励；“实际领取”另外记录领取日期、原发奖日期、邮件编号、物品名/编码和数量。发放和实际领取分开记录，未领取的邮件不会显示为已领取。跳过原因、概率配置变更、抽卡/开箱结果和公告也留日志。

运营日志按服务器本地日期保存：`/opt/xym/data/gm-ops-YYYY-MM-DD.jsonl`；普通管理接口及手动邮件领取审计仍保存于 `/opt/xym/data/gm.log`。规则、概率配置和发奖去重账本保存在各服自己的 MySQL 全局存档中，不放在 APK。数据库备份仍留在对应服务器。
